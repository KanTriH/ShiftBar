<h3 align="center">小店排班，拖一拖就排好</h3>

<p align="center">员工在线报班 · 店长在时间轴上拖拽排班 · 发布后员工一键导入日历</p>

<p align="center">中文 · <a href="README.en.md">English</a></p>

<p align="center">
  <img alt="店长按天排班：每个员工一行，底层的绿色是员工报的可用时间" src="docs/screenshots/zh/manager-schedule.png" width="860">
</p>

## 它解决什么问题

还在用微信群接龙、纸条、Excel 排班吗？员工发来"周三下午有课""周末都行"，店长一条条抄进表格，再截图发回群里，改一次又全乱了。

ShiftBar 把这件事变成四步：**员工自己填 → 店长一屏看全 → 拖拽排好 → 一键发布**。

## 适合谁用

- 靠**手动排班**的小店：奶茶店、咖啡店、餐厅、零售店。
- 一个店长排班、员工很多的团队。
- 有**多家门店、共用同一批员工**的老板。
- 员工流动大，需要区分**试工**和**正式**员工。

ShiftBar 专注把"初排"这件事做好。它不做打卡考勤、不算工资，也不会自动帮你排班：谁上哪个班，由你来决定，它负责让你看得清楚、排得顺手、不出错。

## 怎么用：三步

1. **店长建店**，把"报班链接"发给员工（微信群、短信都行）。
2. **员工打开链接，填自己什么时候能上班**。不用注册，填名字就行。
3. **店长在时间轴上看着大家的空闲时间拖拽排班 → 发布**。员工登录后看到自己的班次，还能导入手机日历。

## 功能

### 店长

- **一屏看全**：每个员工一行，底层半透明的绿色是他们报的可用时间，直接在上面拖出班次。拖动可移动，拖两端可调整时长，点击可编辑，右键可删除（删错了有"撤销"）。
- **自动提醒**：排到员工没空的时间、同一个人的班次重叠、同一时间被排在两家门店，都会用红框标出来。
- **人手一目了然**：时间轴底部按岗位显示每个时段有几个人，一眼看出哪个时段人手太少或太多。
- **自己定义岗位**：名称和颜色都由你定，奶茶店可以是 prep / bar / cashier，餐厅可以是 kitchen / front / host。
- **多家门店共用一批员工**：按门店分别排班，员工报班时选自己能去哪几家；别家门店的班次会用灰色斜纹显示，避免一个人同时排在两处。
- **营业到半夜也没问题**：班次可以跨过午夜，例如 17:45 到次日 01:00。
- **当日任务**：每天可以写下上班的人要做的事（盘点、擦窗户、关制冰机……），员工和导出的班表里都会显示。
- **试工和正式**：试工员工会带标记；在导出的表格样式班表里，试工员工还会单独成组。
- **按周发布**：发布后员工才能看到那一周的班表，发错了可以撤回。
- **导出 PDF**：可以选"表格"或"时间条"样式，按门店或全部门店导出，打印张贴或发群里都方便。
- **加拿大法定假日提醒**：选择你所在的省份，遇到法定假日时在排班、报班和导出的班表里提醒你。
- **一周从周一还是周日开始**，按你们店的习惯设置。

### 员工

- **不用注册也能报班**：打开链接，填名字，选每天能上班的时间。可以选"全天"、多个时段，还能写备注（"下午有课，最好排晚班"）。之后随时回来修改。
- **多门店时选自己能去的**：不选就表示哪家都可以。
- **注册后查看班表**：用店长给的店铺码和名字绑定账号，就能看到已发布的班次，并按周 / 双周 / 月统计自己上了多少小时。
- **一键导入日历**：导出 `.ics` 文件，Google、Apple、Outlook 日历都能导入。
- **手机上也能用**：报班页面和我的班表页面都适配了手机屏幕，不用左右滑动。

### 通用

- 中文和 English 一键切换，默认跟随浏览器语言。
- 深色模式跟随系统设置。
- 不用安装 App，浏览器打开就能用，手机和电脑都行。

## 先试试看（不用注册）

想先看看效果？ShiftBar 带有一个**演示模式**：不用任何账号，数据只保存在你自己的浏览器里。需要电脑上装有 [Node.js](https://nodejs.org)（22.12 或更高版本）：

```bash
git clone https://github.com/KanTriH/shift-scheduler.git
cd shift-scheduler
npm install
npm run dev
```

打开 http://localhost:5173 ，登录页有一键进入"店长"和"员工"的按钮。员工报班链接是 `/s/zhaomu01`。

如果你的店要真正使用，需要有人把它部署到网上（见下面[想自己部署或参与开发](#想自己部署或参与开发)），然后你把网址发给员工就行。

## 使用指南

### 店长：第一次使用

1. **注册**（身份选"店长"），然后**创建店铺**。起个名字，选一个岗位预设（奶茶 / 咖啡店、餐厅、零售店），或者选"我自己来定义"。
2. 进入**设置 > 店铺**：
   - 设置每天的**营业时间**（休息日勾选"休息"；营业到半夜的话，关门时间直接填 `01:00`，系统会当作次日）；
   - 调整**岗位标签**；
   - 有多家店的话，在**门店**里添加；
   - 复制**员工报班链接**，发给员工。
3. 员工报班后，在**可用时间**页能看到每个人每天什么时候有空，以及谁还没报。
4. 进入**排班**页：选一天 → 选"新班次的岗位" → 在员工那一行**拖动**出班次。点击班次可以改岗位、时间和备注，右键可以删除。需要的话，在下面写上**当日任务**。
5. 排好后点**发布本周**，员工就能看到了。发现问题可以点"撤回发布"，改完再发布。
6. 点**导出 PDF**，在弹出的打印窗口里把打印机选成"另存为 PDF"，得到的文件可以打印张贴或发到群里。

红色边框的意思：这个班次排到了员工没空的时间、和同一个人的另一个班次重叠、或者同一时间已在另一家门店排了班。点开班次能看到具体原因。红框只是提醒，不会阻止你保存。

### 员工：报班（不用注册）

1. 打开店长发给你的**报班链接**。
2. 填上你的**名字**（和排班表上的名字保持一致，下次回来会自动带出你上次填的内容）。
3. 选择每天能上班的时间：点"全天"，或者选具体时段；一天可以加多个时段，还能写备注。不选的那天就表示不能上班。
4. 点**提交本周**。可以随时回来修改，也可以用页面上方的箭头切换到下一周，提前报班。

### 员工：查看班表、导入日历

1. **注册**（身份选"员工"）。
2. 输入店长给你的**店铺码**（报班链接 `/s/` 后面的那一段，店长也能在"设置"里看到）和你的名字。**用你之前报班时用的同一个名字**，之前报的班会自动归到你的账号下。
3. 在**我的班表**里查看已发布的班次，左边会统计你这周 / 双周 / 这个月一共上了多少小时。
4. 点**导出到日历**，把下载的 `.ics` 文件导入手机或电脑的日历。

## 常见问题

**员工一定要注册吗？**
不用。报班只需要填名字。只有想查看班表、统计工时、导入日历的时候，才需要注册。

**要装 App 吗？**
不用，浏览器打开就行，手机和电脑都可以。

**忘记密码了怎么办？**
在登录页点"忘记密码？"，输入注册邮箱，会收到一封重置邮件。

**报班时提示"这个名字已被注册员工使用"？**
这个名字已经有人注册并绑定了。如果是你本人，请先登录再填；如果是另一个同名的人，请换个名字，比如加上姓氏或数字。

**我看不到班表？**
先看几件事：店长是不是还没点"发布本周"；你是不是还没用店铺码绑定（员工页显示"绑定你的店铺"的话就是还没绑）；你注册时选的是不是"员工"。

**店长改了"一周从周一开始"，已经发布的班表怎么没了？**
切换一周的起始日后，已经发布的周会变回草稿，需要到排班页重新发布。这是因为"哪一周"的划分变了。

**手机上能排班吗？**
店长的拖拽排班用鼠标或触控笔最顺手，手机上更适合查看。员工在手机上报班、查看班表都可以。

**法定假日提醒准吗？**
只是排班时的提醒，仅供参考。假日是否遇周末顺延、假日工资怎么算，请以你所在省份的官方公告为准。目前支持联邦通用、安大略、不列颠哥伦比亚、艾伯塔、萨斯喀彻温、魁北克。

**怎么注销账号？**
店长在"设置 > 账号"，员工在员工页左下角点"注销账号"，需要输入自己的邮箱确认。**注销后无法恢复。**

## 隐私与数据

- **会保存什么**：你填的名字、注册邮箱、报班时间、排班和备注。
- **谁能看到**：
  - 店长能看到自己店里的全部内容，看不到别人的店；
  - 注册员工只能看到属于自己、并且已经发布的班次；
  - 没登录的访客只能提交自己的报班，看不到别人的报班。但**知道报班链接的人能看到这家店的员工名字列表**，所以请只把链接发给自己的员工，不要发到公开的群里。
- **怎么删除**：店长和员工都可以自己注销账号，数据会被永久删除（店长注销会删除整家店的数据，员工注销只删除自己的）。
- **店主请注意**：系统里有员工的姓名、邮箱和出勤时间，属于个人信息。使用前请确认符合你所在地的隐私规定（例如加拿大的 PIPEDA），并告知员工收集了什么、用来做什么。这不构成法律建议。

## 目前的限制

- **一家店只有一个管理账号**（创建店铺的人），暂时没有副店长一起排班的功能。
- **发布后不会自动通知员工**，需要店长自己通知大家去看班表。
- **访客靠名字识别**：同一家店里重名的人会被当成同一个人，请让他们用不同的名字。
- **跨午夜的班次只算在它开始的那一天**：看次日的排班页时，看不到前一晚延续过来的那一段。
- **店长端的拖拽排班在电脑和平板上最顺手**，手机上更适合查看。
- **法定假日提醒**目前只覆盖上面列出的几个地区，且仅供参考。
- 不提供打卡考勤、不计算工资，也不会自动排班。
